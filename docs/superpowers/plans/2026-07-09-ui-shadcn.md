# Fundación UI — shadcn/ui tematizado a 1a · Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reemplazar el frontend hand-built (inline styles + CSS vars) por **shadcn/ui + Tailwind** tematizado a la identidad **1a — Terminal/amber**, migrando toda la UI existente (layout de 3 regiones + sesiones) y construyendo el **frontend de la terminal de R2** sobre la base nueva.

**Architecture:** Cambio de capa UI únicamente. Se agrega Tailwind + shadcn (componentes copiados a `ui/src/components/ui/`), con un tema oscuro-only que mapea los tokens 1a al formato de shadcn (CSS vars referenciadas directo por Tailwind, sin `hsl()`). Se conserva todo lo no-visual (stores Zustand, transport, registro de módulos, envelope). El backend de terminal de R2 viaja en esta rama.

**Tech Stack:** Vite + React 18 + TS. Tailwind CSS 3, shadcn/ui (Radix + `class-variance-authority` + `clsx` + `tailwind-merge`), `lucide-react`, `@xterm/xterm` + `@xterm/addon-fit`. vitest + @testing-library/react + **@testing-library/user-event** (para las interacciones Radix).

Spec: `docs/superpowers/specs/2026-07-09-ui-shadcn-design.md`.

## Global Constraints

- **Identidad 1a vía shadcn (regla #1 actualizada):** look/pulido nativo de shadcn, **tematizado** a los tokens 1a. El mockup es referencia, no objetivo pixel. Tokens exactos: accent `#e0863f`, appBg `#161513`, panelBg `#1c1a17`, titleBg `#131210`, terminalBg `#0f0e0c`, border `#332f28`, textPrimary `#f0ece4`, textMuted `#75705f`, selectedBg `#2e2820`, status running/idle/done `#7fb069`/`#7d7568`/`#6b8fbf`.
- **Mapeo tema → shadcn vars** (hex directo, Tailwind los referencia sin `hsl()`): `--background:#161513`, `--foreground:#f0ece4`, `--card`/`--popover:#1c1a17`, `--primary:#e0863f`, `--primary-foreground:#161513`, `--muted:#211e1a`, `--muted-foreground:#75705f`, `--accent:#2e2820`, `--accent-foreground:#f0ece4`, `--border`/`--input:#332f28`, `--ring:#e0863f`, `--radius:0.5rem`. Vars propias: `--title-bg:#131210`, `--terminal-bg:#0f0e0c`, `--status-running/idle/done`, `--role-pill-bg:#2e2820`.
- **Sin estilo mixto:** al terminar, ningún componente de app usa inline-styles-1a viejos; todo es Tailwind/shadcn. (Excepción legítima: `paddingLeft` dinámico por profundidad en el árbol, y el `theme` de xterm que es JS.)
- **Sin fallos silenciosos:** sin cambios (transport). **TDD:** cada migración mantiene el comportamiento verificado; los tests que dependían de mecánica nativa (`<select>` + `fireEvent.change`) se **reescriben** a la interacción Radix (userEvent), asertando el mismo comportamiento — nunca aflojando una aserción para que pase.
- Frontend en `ui/`. Commits: conventional, atómicos, en español; uno por tarea.

```tsx
import { X } from "lucide-react";
import { useStore } from "../state/store";
import { cn } from "../lib/utils";

export function TabStrip() {
  const { openTabs, activeTabId, closeTab } = useStore();
  const tabCls = (active: boolean) =>
    cn("flex items-center gap-1.5 px-3 py-1.5 text-xs border-b-2",
       active ? "text-foreground border-primary" : "text-muted-foreground border-transparent");
  return (
    <div className="flex border-b border-border bg-title-bg">
      <div className={tabCls(activeTabId === "chat")}>Chat</div>
      {openTabs.map((t) => (
        <div key={t.id} className={tabCls(activeTabId === t.id)}>
          {t.label}
          <button aria-label={`cerrar ${t.label}`} onClick={() => closeTab(t.id)}
            className="text-muted-foreground hover:text-foreground"><X size={12} /></button>
        </div>
      ))}
    </div>
  );
}
```

```tsx
        <ChevronRight size={12}
          onClick={(e) => { e.stopPropagation(); if (hasChildren) toggleExpanded(node.id); }}
          className={cn("shrink-0 text-muted-foreground transition-transform",
            hasChildren ? "visible" : "invisible", node.expanded && "rotate-90")} />
        <span className={cn("h-[7px] w-[7px] shrink-0 rounded-full", DOT[node.status])} />
        {editingId === node.id ? (
          <Input autoFocus value={draft} onClick={(e) => e.stopPropagation()}
            onChange={(e) => setDraft(e.target.value)}
            onKeyDown={(e) => {
              if (e.key === "Enter") { renameSession(getWs(), node.id, draft).catch((err) => console.error("rename falló", err)); stopRename(); }
              if (e.key === "Escape") stopRename();
            }}
            onBlur={stopRename} className="h-5 flex-1 px-1 py-0 text-xs" />
        ) : (
          <span className="flex-1 truncate"
            onDoubleClick={(e) => { e.stopPropagation(); setDraft(node.name); startRename(node.id); }}>
            {node.name}
          </span>
        )}
        {node.role && <Badge variant="secondary" className="bg-role-pill text-primary text-[10px] px-1.5 py-0">{node.role}</Badge>}
        <Plus size={13} onClick={(e) => { e.stopPropagation(); openModal(node.id); }} className="shrink-0 text-muted-foreground" />
      </div>
      {node.expanded && node.children.map((c) => <SessionNodeRow key={c.id} node={c} depth={depth + 1} />)}
    </div>
  );
}
```
